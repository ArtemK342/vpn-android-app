// Юридические документы

Политика конфиденциальности.

Последнее обновление: 25 апреля 2026 · Версия 1.1

// 01

Общие положения

Настоящая Политика конфиденциальности описывает, какие данные собирает и хранит VPN-сервис fsociety VPN, а также как эти данные используются и защищаются.

Используя Сервис, вы соглашаетесь с условиями настоящей Политики.

// 02

Политика нулевых логов

Мы не храним и не собираем:

  • Историю интернет-активности пользователя
  • IP-адреса пользователей при VPN-подключении
  • Время и продолжительность VPN-сессий
  • Данные DNS-запросов
  • Информацию об объёме и содержании трафика
  • Приватные ключи шифрования
  • Метаданные подключений
Мы технически не способны предоставить данные о вашей активности третьим лицам — потому что мы их не собираем.
// 03

Email-аккаунты

Для работы email-аккаунта мы храним только:

  • Email-адрес
  • Хэш пароля (не сам пароль)
  • Статус подписки
  • Публичный WireGuard-ключ

Приватный ключ генерируется на лету на вашем устройстве и никогда не передаётся на наши серверы.

Все данные хранятся в Швейцарии.

// 04

Анонимные аккаунты

Для анонимных аккаунтов (вход по 16-значному коду) мы не храним ни email, ни пароль. Хранится только:

  • Хэш кода доступа
  • Статус подписки
  • Публичный VPN-ключ
Это максимально возможный уровень приватности в рамках функционирующего сервиса. Мы не можем идентифицировать вас как личность.

При создании анонимного аккаунта IP-адрес фиксируется исключительно для ограничения частоты создания аккаунтов (rate limiting) и не связывается с вашей VPN-активностью.

// 05

Данные для оплаты

Оплата производится через Telegram Stars. Мы не получаем и не храним данные банковских карт. Платёжная информация обрабатывается Telegram в соответствии с их политикой конфиденциальности.

// 06

Данные поддержки

При обращении в поддержку мы храним переписку тикетов для решения вашего вопроса. После закрытия тикета и удаления аккаунта все данные удаляются.

// 07

Передача данных третьим лицам

Мы не продаём, не передаём и не раскрываем ваши персональные данные третьим лицам.

Поскольку мы не храним логи активности — мы не можем выдать их ни по запросу властей, ни по иным основаниям.

// 08

Удаление данных

Вы можете удалить аккаунт в любое время через настройки. При удалении все связанные данные немедленно удаляются с наших серверов.

// 09

Контакты

По вопросам, связанным с настоящей Политикой, обращайтесь через форму поддержки в приложении или через Telegram. Мы отвечаем в течение 24 часов.
