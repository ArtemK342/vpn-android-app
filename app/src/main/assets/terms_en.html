Service Description

fsociety VPN is a commercial VPN service using the AmneziaWG protocol. The Service encrypts internet traffic and masks the user's real IP address, replacing it with the address of our servers.

The Service is intended solely for protecting user privacy and security on the internet.

We maintain infrastructure in multiple jurisdictions. The list of available servers and countries may change — we strive to expand it.

Zero-Log Policy

We do not store or collect:

  • User internet activity history
  • User IP addresses upon connection
  • VPN session time and duration
  • DNS query data
  • Traffic information and volume
  • Private encryption keys
  • Connection metadata
We are technically unable to provide data about your activity to third parties — because we do not collect it.

For email accounts we store only: email address, password hash, subscription status, and public WireGuard key. The private key is generated on the fly and never stored on our servers. Data is stored in Switzerland.

For anonymous accounts (login via 16-digit code) we store no email or password — only the code hash, subscription status, and public VPN key.
